# Scriptloader (v2)

Lets track-scripts load scripts from online sources.

If your script requires to add ini keys to configure, you can do that. They are supported and passed along.

---

Download [this script](https://raw.githubusercontent.com/Pivot-Point-Labs/scripts/refs/heads/main/scriptloader/scriptloader_v2.lua), place it in your extension folder and copy this into your `ext_config.ini`.

```ini
[SCRIPT_...]
SCRIPT=scriptloader_v2.lua
online_url="..."
```
